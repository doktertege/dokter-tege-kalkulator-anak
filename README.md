# Dokter Tege - Kalkulator Dosis Anak

Prototype Android offline untuk uji tampilan dan navigasi.

## Build APK
Buka tab **Actions** lalu jalankan workflow **Build Android APK**. Setelah selesai, unduh artifact `Dokter-Tege-Kalkulator-Anak-APK`.

## Status keselamatan
Versi ini hanya prototype UI/katalog obat. Kalkulasi dosis klinis belum diaktifkan. Jangan gunakan untuk keputusan terapi pasien. Sebelum rilis klinis, setiap obat memerlukan regimen tervalidasi berdasarkan indikasi, usia, BB, sediaan/konsentrasi, rute, interval, durasi, dosis maksimal, kontraindikasi, serta referensi tepercaya.

Aplikasi tidak meminta izin internet dan memuat antarmuka dari asset lokal.
